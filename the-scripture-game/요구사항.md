🎨 웹 기반 게임의 4대 시각화/이펙트 기술
1. HTML5 <canvas> (코어 렌더링 엔진) 웹 브라우저 안에 '투명한 도화지'를 깔아놓고 자바스크립트로 그림을 그리는 기술입니다.

용도: 테트리스 블록이 부드럽게 떨어지고, 줄이 맞춰졌을 때 블록이 산산조각 나며 파티클(불꽃 조각)이 사방으로 튀는 타격감 있는 이펙트를 초당 60프레임으로 부드럽게 그려냅니다.
2. CSS3 애니메이션 & 필터 (다이나믹 연출) 웹 디자인에 쓰이는 CSS 기술은 게임 연출에 있어서 최고의 무기입니다.

화면 암전: 내가 공격하면 상대방 게임판 전체에 backdrop-filter를 걸어 으스스하게 만들거나 화면을 완전히 깜깜하게 만듭니다.
화면 흔들림(Screen Shake): 큰 공격이 들어갈 때 CSS 애니메이션을 이용해 브라우저 내부의 게임판 전체를 지진 난 것처럼 덜덜 떨리게 만듭니다. (이게 타격감의 핵심입니다!)
마귀 팝업: 투명한 배경의 마귀 이미지(PNG, WebP)가 CSS의 transform 속성을 타고 화면으로 쑥 튀어나오거나 빙글빙글 돌면서 나타나게 합니다.
3. Web Audio API (사운드 연출) 시각 효과가 50%라면, 나머지 50%는 청각입니다. 화면이 어두워질 때 "스스슥..." 하는 공포스러운 소리나, 블록이 터질 때의 찰진 타격음을 지연 없이 동기화해서 재생해 도파민을 터뜨리게 해줍니다.

4. WebGL (선택 사항: PixiJS 등) 만약 화면 공간 자체가 일그러지거나(블랙홀 효과), 불길이 활활 타오르는 압도적인 3D급 이펙트가 필요하다면 그래픽 카드(GPU) 자원을 100% 끌어다 쓰는 WebGL 기술을 사용할 수도 있습니다. (하지만 기획하신 뿌요뿌요 수준의 연출은 Canvas와 CSS3 조합만으로도 차고 넘치게 훌륭한 퀄리티를 뽑아낼 수 있습니다.)
