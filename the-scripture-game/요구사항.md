## 1. 게임 개요

### 1.1 한 줄 컨셉
**"우리는 혈과 육에 대한 싸움이 아니다"** — 두 플레이어가 각각 성경 위인을 골라 테트리스로 대결합니다. 줄을 지우면 **악한 영(마귀)** 이 상대 화면에 나타나 방해합니다. 지킬 때는 **천사(그룹·스랍·미가엘 등)** 와 **하나님의 전신갑주**를 씁니다.

> *"For we wrestle not against flesh and blood, but against principalities, against powers, against the rulers of the darkness of this world, against spiritual wickedness in high places."* — Ephesians 6:12 (KJV)

### 1.2 확정된 결정 사항 (v1의 열린 질문에 대한 답)
| 질문 | 결정 |
|---|---|
| 게임 규칙 | **테트리스 룰** (가로줄 완성 시 삭제, 7-bag 랜덤, 홀드, 고스트, 하드드롭) |
| 방해 블록 | **포함**: 마귀 연출(암전·조작 반전 등)과 **쓰레기 줄 상승**을 함께 사용 |
| 프로젝트 위치 | `Tetris-Battle/` 폴더 유지 |
| 인프라 | Oracle/Vercel 대신 **Cloudflare Pages + Workers + Durable Objects + Supabase** |
| 테마 | KJV 성경 기반 영적 전쟁 (위인 · 천사 · 악한 영) |

### 1.3 게임 모드
1. **대전 모드 (PvP)**: 1차 목표. 실시간 1:1 매칭과 친구 초대 코드를 지원합니다.
2. **스토리 모드 (PvE)**: 2차 목표. AI가 조종하는 악한 영 보스와 단계별로 싸우고, 최종 보스는 **용(옛 뱀, 사탄)** 입니다. 이기면 새 위인이 해금됩니다.
3. **연습 모드**: 혼자 플레이하며 위인 스킬을 익힙니다.

## 2. 핵심 게임 시스템

### 2.1 기본 테트리스 규칙
- 10×20 보드, 7종 테트로미노, **7-bag** 생성 방식 (대전 시 두 플레이어에게 **같은 시드**를 주어 공정성 확보)
- 홀드, 고스트 피스, 하드/소프트 드롭, SRS 회전(벽차기 포함)
- 콤보, Back-to-Back, T-Spin 판정

### 2.2 공격: 악한 영 소환
줄을 지우면 공격력이 쌓이고, 공격력에 따라 **상대 화면에 악한 영이 나타납니다**. 쓰레기 줄 공격과 영적 방해 효과가 함께 들어갑니다.

| 내 플레이 | 쓰레기 줄 | 소환되는 악한 영 (예시) |
|---|---|---|
| 2줄 | 1 | 더러운 귀신 (짧은 암전) |
| 3줄 | 2 | 군대(Legion) |
| 4줄 (테트리스) | 4 | 공중 권세 잡은 자 / 아바돈 중 무작위 |
| T-Spin, 연속 콤보 | +1~3 | 등급이 높은 악한 영 |
| 백투백 테트리스 | 4+ | 큰 음녀 바벨론 · 이세벨의 영 등 상위 등급 |

### 2.3 방어: 믿음 게이지와 전신갑주
- 줄을 지울 때마다 **믿음 게이지(Faith)** 가 찹니다.
- 게이지를 써서 **위인 고유 스킬**을 쓰거나 **천사를 부릅니다**.
- 들어오는 쓰레기 줄은 상쇄(카운터)됩니다. 내가 줄을 지우면 받을 공격이 먼저 줄어듭니다.
- **하나님의 전신갑주** 아이템이 보드에 무작위로 나타나고, 그 줄을 지우면 얻습니다 (Ephesians 6:13–17).

| 아이템 | 효과 | 근거 |
|---|---|---|
| 진리의 허리띠 | 조작 반전(미혹) 무효 | Eph 6:14 |
| 의의 흉배 | 쓰레기 줄 1회 경감 | Eph 6:14 |
| 평안의 복음의 신 | 낙하 속도 증가 무효 | Eph 6:15 |
| 믿음의 방패 | 다음 공격 1회 완전 차단 | Eph 6:16 *"quench all the fiery darts of the wicked"* |
| 구원의 투구 | 암전·시야 방해 무효 | Eph 6:17 |
| 성령의 검(말씀) | 받은 공격 1회를 상대에게 되돌림 | Eph 6:17 |

### 2.4 승리 조건
- 상대 블록이 천장에 닿으면(Top-out) 승리합니다. 3판 2선승제입니다.
- 승리하면 KJV 구절과 함께 승리 연출이 나옵니다. 예: *"I have fought a good fight, I have finished my course, I have kept the faith"* — 2 Timothy 4:7

### 3.2 예수님 (특별 존재 — 플레이어블 아님)

### 3.5 균형 원칙
- 악한 영 효과는 **최대 6초** (봉인류 제외)이며, 같은 효과는 겹쳐 쌓이지 않습니다.
- 모든 방해 효과에 대응하는 천사나 갑주가 반드시 1개 이상 있습니다. 상성표는 `content/` JSON으로 관리합니다.
- 연출은 무섭게 하되 **고어·선정 표현은 하지 않습니다** (전 연령 목표).

## 4. 시스템 사양 (아키텍처)

### 4.1 전체 구성
```
[브라우저 A] ──WebSocket──┐                     ┌──> Supabase Auth (로그인 JWT 발급)
                          ├─> Cloudflare Worker ─┤
[브라우저 B] ──WebSocket──┘   (라우팅·인증)       └──> Supabase Postgres (전적·랭킹 저장)
                                   │
                    ┌──────────────┴──────────────┐
                    ▼                             ▼
           Durable Object: Matchmaker     Durable Object: GameRoom (방 1개 = 인스턴스 1개)
           (대기열, 친구 코드)              (두 플레이어 연결, 공격 계산·중계, 승패 판정)

[정적 화면] Cloudflare Pages ── HTML / CSS / JS / 이미지 / 사운드
```

### 4.2 구성 요소별 사양
| 계층 | 기술 | 역할 |
|---|---|---|
| 프론트엔드 호스팅 | **Cloudflare Pages** | 정적 파일 배포, 전 세계 CDN |
| 렌더링 | **PixiJS v8** (WebGL/WebGPU) + pixi-filters | 보드, 블록, 파티클, 발광·충격파 필터 |
| 연출 | **GSAP 3** + **CSS3** (`backdrop-filter`, keyframes) DOM 오버레이 | 암전, 흔들림, 악한 영·천사 등장, 자막 |
| 사운드 | **Tone.js** (Web Audio 기반) | 합성 효과음, 적응형 BGM |
| 실시간 서버 | **Cloudflare Workers + Durable Objects** (WebSocket Hibernation API) | 매칭, 방 관리, 공격 중계·판정 |
| 언어 | 클라이언트: 바닐라 JS (ES Modules) / 서버: **TypeScript** | 빌드 도구 최소화 |
| 인증 | **Supabase Auth** (구글 · 카카오 · 게스트 익명 로그인) | Worker가 JWT 검증 |
| 데이터베이스 | **Supabase Postgres** + RLS | 프로필, 전적, 랭킹, 해금 |
| 게임 콘텐츠 | 저장소 내 `content/*.json` | 캐릭터, 구절, 상성표 (git으로 버전 관리) |
| 배포 도구 | `wrangler` (Workers/Pages), `supabase` CLI (마이그레이션) | |

> Socket.IO는 Cloudflare Workers에서 동작하지 않으므로 **브라우저 기본 WebSocket**으로 바꿉니다. 기존 `server/`(Express + Socket.IO)는 이전이 끝나면 삭제합니다.

### 4.3 실시간 통신 프로토콜 (JSON over WebSocket)
**클라이언트 → 서버**
| 메시지 | 내용 |
|---|---|
| `join` | `{ token, heroId, roomCode? }` |
| `ready` | 준비 완료 |
| `state` | `{ seq, board(압축), active, score }`: 초당 10~15회, 상대 화면 표시용 |
| `clear` | `{ seq, lines, combo, b2b, tspin, pieceCount }`: 공격 계산용 |
| `skill` | `{ skillId }`: 위인 스킬, 천사 소환 |
| `topout` | 게임 오버 |

**서버 → 클라이언트**
| 메시지 | 내용 |
|---|---|
| `matched` | `{ roomId, opponent: { nickname, heroId } }` |
| `start` | `{ seed, countdown }`: 같은 7-bag 시드 |
| `opponentState` | 상대 보드 스냅샷 |
| `attack` | `{ spiritId, garbage, holeColumn, duration }` |
| `effect` | 천사, 갑주, 스킬 발동 연출 |
| `roundEnd` / `matchEnd` | 승패, 통계 |

**서버 권한(부정행위 방지 기본선)**
- 공격력과 소환할 악한 영은 **서버(GameRoom)가 결정**합니다. 클라이언트는 지운 줄 정보만 보냅니다.
- `seq` 번호와 `pieceCount`로 불가능한 진행을 걸러냅니다. 예: 블록 수보다 많은 줄 삭제, 초당 비정상 횟수.
- 스킬 쿨다운과 믿음 게이지도 서버에서 관리합니다.

### 4.4 Supabase 데이터 모델 (초안)
```sql
profiles   (id uuid PK → auth.users, nickname text unique, rating int default 1000, created_at)
matches    (id uuid PK, room_id text, player1 uuid, player2 uuid, winner uuid,
            hero1 text, hero2 text, duration_ms int, stats jsonb, created_at)
unlocks    (user_id uuid, hero_id text, unlocked_at, PK(user_id, hero_id))
leaderboard (VIEW: profiles 기준 rating 상위 100명)
```
- **RLS**: 본인 프로필만 수정할 수 있고, 랭킹 뷰는 전체 공개입니다.
- `matches`는 **Worker만 기록**합니다. Supabase service role 키는 `wrangler secret`으로 보관하고 클라이언트에는 절대 노출하지 않습니다.
- 클라이언트에는 `anon` 공개 키만 넣습니다.

### 4.6 키 없이 로컬 실행 (1차 개발 기준)
외부 서비스 키(Cloudflare 계정, Supabase URL/키)가 **하나도 없어도** 로컬에서 전부 동작해야 합니다.
| 구성 | 로컬 모드 (키 없음) | 운영 모드 (키 있음) |
|---|---|---|
| 실시간 서버 | `wrangler dev`: Workers와 Durable Objects를 로컬 런타임(workerd)에서 실행, 로그인 불필요 | Cloudflare에 배포 |
| 로그인 | **게스트 닉네임** (브라우저에 저장) | Supabase Auth |
| 전적·랭킹 | Durable Object 내장 SQLite 저장소 (로컬 파일) | Supabase Postgres |
| 전환 방법 | `.dev.vars`에 키가 없으면 자동으로 로컬 모드 | `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` 설정 시 자동 전환 |

### 4.7 비용 (무료 플랜 기준, 출시 전 요금표 재확인 필요)
- **Cloudflare**: Pages와 Workers 무료 플랜으로 시작합니다. Durable Objects는 SQLite 기반으로 무료 플랜에서도 쓸 수 있습니다. 소규모 동시접속은 무료 범위 안입니다.
- **Supabase 무료 플랜**: DB 500MB 수준입니다. **7일 동안 접속이 없으면 프로젝트가 일시정지**되므로, 정식 운영 시 Pro 플랜이나 주기적 접속을 고려합니다.

## 5. 디자인 · 액션 · 사운드 · 재미 (핵심 요구사항 — 강화)

> 이 게임의 승부처는 **연출**입니다. 기능이 같아도 "손맛"과 "화면의 박력"이 없으면 실패로 봅니다. 아래 항목은 선택이 아니라 **필수 요구사항**입니다.

### 5.1 아트 방향
- **톤**: "어둠 속에 비치는 빛". 다크 판타지 배경 위에 금빛과 흰빛의 성스러운 네온을 씁니다.
- **블록**: 7종 블록을 성막 재료 색(금, 은, 청색, 자색, 홍색 실 — Exodus 26:1)으로 칠합니다. 유리 질감, 하이라이트, **은은한 발광(Glow)** 을 줍니다.
- **배경**: 여러 층의 시차(Parallax) 배경입니다. 하늘의 빛, 구름, 떠다니는 빛 입자가 천천히 움직입니다. 공격을 받으면 배경이 붉고 어둡게 변합니다.
- **악한 영**: 실루엣과 연기 중심의 반투명 연출로, 공포감은 주되 혐오스럽지 않게 합니다.
- **천사**: 빛 · 날개 · 불꽃 모티프. 그룹은 네 얼굴과 바퀴(Ezek 10), 스랍은 여섯 날개(Isa 6:2)로 표현합니다.
- **위인**: 초상 카드 일러스트 (AI 생성 후 보정, 또는 외주). 1차 개발에서는 **코드로 그린 벡터 문장(紋章, 엠블럼)** 으로 대체해 외부 이미지 없이도 완성도를 냅니다.
- **폰트**: 영어 구절은 Cinzel, 한글은 Noto Serif KR. `@fontsource`로 번들에 포함해 **오프라인에서도** 표시합니다.

### 5.2 액션 · 타격감 (Game Feel / Juice)
| 순간 | 필수 연출 |
|---|---|
| 블록 이동·회전 | 미세한 이동 보간(트윈), 회전 시 잔상 |
| 하드 드롭 | 낙하 궤적의 빛줄기 + 착지 충격파 + 작은 화면 흔들림 |
| 1~3줄 삭제 | 줄이 하얗게 번쩍인 뒤 **블록이 조각나 파티클로 폭발** |
| 테트리스(4줄) | 화면 흔들림(강), 0.08초 **히트스톱**, 충격파 필터, "TETRIS" 대형 글자 등장 |
| 콤보 | 콤보 수가 커질수록 글자 크기·색·떨림 증가, 음 높이가 올라감 |
| T-Spin / 백투백 | 금빛 섬광 + 전용 문구 + 전용 효과음 |
| 공격 발사 | 내 보드에서 상대 보드로 **빛의 화살(투사체)** 이 날아가는 궤적 |
| 공격 받음 | 보드가 붉게 번쩍이고 흔들림, 경고 게이지가 차오름 |
| 악한 영 등장 | 화면 가장자리 비네트 어둠, 연기 파티클, 영 이름과 KJV 구절 자막 |
| 천사·스킬 발동 | 위에서 빛기둥이 내려오고, 날개 파티클 + 성가 화음 |
| 위기(블록이 위험선 근처) | 심장박동 효과음 + 보드 테두리 붉은 맥동 |
| 승리 / 패배 | 승리: 빛 폭발 + 금빛 콘페티 + 구절 / 패배: 보드가 회색으로 굳으며 무너짐 |
| 모바일 | 진동(`navigator.vibrate`) 피드백, 터치 스와이프 조작 |

- 모든 연출에 **옵션 메뉴로 세기 조절**(흔들림 끄기, 섬광 줄이기)을 둡니다. 광과민성 배려입니다.
- 60fps를 유지해야 하며, 파티클은 오브젝트 풀링으로 재사용합니다.

### 5.3 사운드
- **효과음 (모두 필수)**: 이동, 회전, 소프트/하드 드롭, 착지, 홀드, 1~4줄 삭제(줄 수마다 다른 음), 콤보 상승음, T-Spin, 공격 발사, 공격 받음, 악한 영 등장(저음 드론), 천사 등장(합창 화음), 스킬 발동, 카운트다운, 승리 팡파르, 패배.
- **배경음악**: 대기실과 대전 BGM입니다. 위기 상황에서는 템포와 긴장감이 올라가는 **적응형 음악**으로 만듭니다.
- 1차 개발은 **음원 파일 없이 코드로 합성**(Tone.js)합니다. 저작권 걱정 없이 바로 동작하고, 이후 녹음 음원으로 바꿀 수 있습니다.
- 음량 조절(마스터 / 효과음 / 음악)과 음소거를 지원합니다.

### 5.4 재미 요소
- **역전 장치**: 위기 시 에스더 자동 발동, 예수님 "세상을 이기었노라" 이벤트로 끝까지 긴장감을 유지합니다.
- **보는 재미**: 상대 보드를 실시간으로 보여 주고, 공격이 오가는 궤적이 화면 가운데에서 부딪히며 **상쇄되는 연출**을 넣습니다.
- **수집과 성장**: 위인 해금, 열두 제자 카드, 업적. 예: "골리앗 사냥꾼" — 다윗으로 한 경기 테트리스 5회.
- **말씀 카드**: 경기 결과 화면에 그 경기의 대표 구절 카드를 보여 주고, 이미지로 저장하거나 공유할 수 있습니다.
- **감정 표현**: 대전 중 짧은 리액션(🙏 아멘, 🔥 할렐루야, 😇)을 보낼 수 있습니다. 채팅은 없습니다.
- **AI 상대**: 혼자서도 바로 즐기도록, 난이도 3단계(쉬움·보통·어려움) 봇과 대전합니다.

### 5.5 재미 설계 근거 (학술 이론 적용)
> 근거 자료: [게임재미설계-학술자료.md](게임재미설계-학술자료.md). 아래 기능은 그 체크리스트(§10)를 그대로 대입한 결과이며 **필수 요구사항**입니다.

#### (1) 말씀 대결 — 성경 퀴즈 (Serious Fun + People Fun)
- 대전 중 **말씀 블록**(빛나는 칸이 박힌 블록)이 들어 있는 줄을 지우면 **말씀 대결**이 열립니다. 아무도 못 지우면 90초마다 자동으로 열립니다.
- 두 플레이어 화면이 **동시에 멈추고** KJV 기반 4지선다 문제가 나옵니다. 제한 시간은 10초입니다.
- **서버가 도착 순서로 판정**합니다. 먼저 맞힌 사람이 보상(믿음 게이지 +50% 또는 무작위 전신갑주)을 받고, 틀리면 3초 동안 다시 고를 수 없습니다.
- **니어미스 연출**: 둘 다 맞혔는데 늦은 쪽에는 "0.12초 차이!"를 크게 보여 줍니다 (§7 니어미스).
- 문제는 `content/quiz.json`에서 관리합니다 (인물·사건·구절 빈칸 채우기, 난이도 3단계). 1차 개발 분량은 최소 60문항입니다.
- 정답 해설에 KJV 원문 구절과 출처를 보여 줍니다.

#### (2) 특수 블록 (가변 보상 — 결제 없음)
| 특수 블록 | 등장 | 효과 |
|---|---|---|
| 말씀 블록 (빛나는 칸) | 블록 7~12개마다 무작위 1개 | 그 줄을 지우면 말씀 대결 |
| 여리고 나팔 블록 (폭탄) | 낮은 확률, 콤보 중 확률 상승 | 지우면 주변 3×3 블록 폭파 + 공격력 +1 |
| 만나 블록 | 위기 상황일수록 확률 상승 | 지우면 믿음 게이지 +25% |

- 등장 간격은 **고정이 아닌 가변 확률**입니다 (§2 가변비율 강화).
- ⚠️ **윤리 원칙**: 이 게임에는 **현금 결제, 확률형 유료 아이템(가챠)이 없으며 앞으로도 넣지 않습니다**. 가변 보상은 "다음 판이 궁금해지는 정도"까지만 씁니다.

#### (3) 몰입 채널 유지 장치 (§1 Flow, §8 손실 회피)
- **난이도 곡선**: 낙하 속도는 경기 시작 후 완만하게 오르고, 2분 뒤부터 가속합니다.
- **실력 보정**: 연속 3판 진 플레이어는 다음 판에서 받는 쓰레기 줄 −1, 믿음 게이지 충전 +15%를 받습니다. 화면에는 "은혜(Grace)" 아이콘으로만 은은하게 표시합니다.
- **매칭**: 레이팅(Elo) 차이가 작은 상대부터 찾습니다. AI 봇 상대는 난이도를 고를 수 있습니다.
- **방해 상한**: 악한 영 효과는 최대 6초이고, 동시에 2개까지만 걸립니다. 같은 효과는 겹치지 않으며, 효과가 끝나면 1.5초 동안 같은 종류를 다시 받지 않습니다.
- **단계적 해금**: 첫 3판은 특수 블록 없이 기본 규칙과 스킬만 나옵니다. 그 뒤 말씀 블록, 여리고 나팔 블록 순서로 열립니다.

#### (4) 타격 피드백 동기화 (§3 보상 예측 오차, §4 Juice)
- 콤보가 이어질수록 배경 빛, 음 높이, 화면 테두리 맥동이 **점점 고조**됩니다. 콤보가 터지는 순간에는 **히트스톱(0.05~0.1초) + 파티클 + 흔들림 + 효과음이 같은 프레임에** 나옵니다.
- **아쉬움 연출 (니어미스)**: 테트리스 직전에 콤보가 끊기거나 1칸 차이로 지면 "아깝다!" 문구와 함께 놓친 줄을 잠깐 강조합니다.

#### (5) 자율성 · 유능감 (§5 자기결정이론)
- 스킬, 천사 소환, 획득한 전신갑주는 **자동 발동이 아니라 플레이어가 직접 고른 키**로 씁니다. 예외는 에스더 패시브입니다.
- 경기가 끝나면 개인 기록(최대 콤보, 분당 공격, 퀴즈 정답률)과 **이전 판 대비 성장 수치**를 보여 줍니다.

#### (6) 체크리스트 충족 표
| 체크 항목 | 충족 장치 |
|---|---|
| 몰입 채널 밸런싱 | 난이도 곡선, 은혜 보정, Elo 매칭, 봇 난이도 |
| 예측 불가능한 보상 (결제 없이) | 특수 블록 가변 확률, 무작위 전신갑주 |

## 7. 검증 계획

### 7.1 로컬
1. `cd worker && npx wrangler dev`: Worker와 Durable Object를 로컬에서 실행
2. `client/`를 로컬 정적 서버로 열고, 브라우저 창 2개로 플레이어 A와 B 접속
3. A가 테트리스(4줄)를 지우면 B 화면에 **즉시** 쓰레기 4줄과 상위 악한 영 연출이 나타나는지 확인
4. B가 믿음의 방패 · 미가엘 · 다니엘 스킬로 막을 수 있는지 확인
5. Supabase는 `supabase start`(로컬) 또는 개발용 프로젝트에 연결해 전적 기록 확인

### 7.2 자동 테스트
- `attack.ts`: 줄 수, 콤보, B2B, T-Spin별 공격력과 소환 표 → **Vitest 단위 테스트**
- 테트리스 엔진: 회전 벽차기, 줄 삭제, 7-bag 분포 테스트
- `content/*.json`: 모든 캐릭터에 KJV 출처 구절이 있는지 검사하는 스크립트

### 7.3 성능 목표
- 렌더링 60fps (중급 모바일 기준)
- 공격 반영 지연: 같은 국가 기준 100ms 이하
